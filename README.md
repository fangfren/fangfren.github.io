# fangfren.github.io

Renff的个人主页

## 内容

- 个人简介与当前学习/研究/方向，以及其他兴趣爱好
- 个人博客文章列表与详情阅读
- 公开项目入口

## 本地生成内容与 RSS

运行以下命令会重新生成文章页、`feed.xml`、`sitemap.xml` 和 `robots.txt`：

```powershell
npm run build
```

如果使用 VS Code，也可以直接运行默认构建任务 `Build site and RSS`，或按
`Ctrl + Shift + B`。该过程只生成本地文件，不会提交或推送 Git 内容。
